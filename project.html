Core Concepts

Flow Designer

Flow Designer is a ServiceNow tool used to automate business processes using triggers, actions and conditions.

Ticket Classification

Ticket classification identifies the category and priority of a support ticket based on the issue reported by the user.

Auto Assignment

After classification, the ticket can be automatically assigned to the appropriate support group.

Flow Designer Implementation

1

Ticket Created

User submits a new support ticket describing the issue.

2

Classification

Flow checks the ticket category and issue type.

3

Assignment

Ticket is automatically assigned to the correct support group.

4

Notification

User receives a notification about the ticket classification and assignment.
